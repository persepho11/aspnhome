01 HOW 소개

개발을 시작하기 전,
비용과 추진 방향부터 확인하세요.

ASPN이 AI 기반 개발 견적 서비스 ‘HOW’를 새롭게 선보입니다. HOW는 개발 요구사항과 RFP, 참고자료를 바탕으로 개발 프로젝트의 범위, 예상 공수, 비용, 일정, 투입 인력 및 수행계획을 사전에 검토할 수 있도록 지원합니다.

02 개발 전 가장 먼저 확인할 것

“얼마나 들고, 얼마나 걸릴까?”
개발은 이런 질문에서 시작됩니다.

초기에는 요구사항이 완전히 정리되지 않았거나 RFP와 참고자료만으로 개발 가능성과 예산을 검토해야 하는 경우가 많습니다. HOW는 이 단계에서 필요한 정보를 구체화합니다.

이런 시스템을 실제로 만들 수 있을까요?

요구사항을 바탕으로 구현 방향과 검토할 개발 범위를 정리합니다.

개발 비용과 기간은 얼마나 필요할까요?

기능별 예상 공수와 비용, 일정 및 필요한 인력을 함께 검토합니다.

내부 보고는 어떻게 준비해야 할까요?

프로젝트 추진 여부를 검토할 수 있도록 견적과 수행계획을 제공합니다.

처음부터 개발 미팅이 필요한가요?

온라인으로 요구사항과 자료를 먼저 제출하고 결과 확인 후 후속 협의를 진행할 수 있습니다.

05 AI 분석 + 전문가 검토

AI로 요구사항을 정리하고,
전문가 검토로 추진안을 구체화합니다.

HOW는 AI만으로 개발 견적을 자동 확정하는 서비스가 아닙니다. 입력된 개발 요구사항과 첨부자료를 분석해 개발 기능과 범위 등을 정리하고, 예상 공수·비용·일정·인력과 수행계획을 검토한 뒤 전문가 검토를 거쳐 결과를 제공합니다.

STEP 01요구사항 분석

개발 기능, 업무 흐름, 연계 대상과 검토 범위를 정리합니다.

STEP 02공수·비용 검토

기능별 예상 공수와 비용, 역할별 투입 인력을 검토합니다.

STEP 03수행계획 검토

프로젝트 단계별 예상 일정과 주요 산출물을 검토합니다.

STEP 04전문가 검토

분석 내용을 전문가가 검토하고 견적 결과와 수행계획을 제공합니다.

Q

SI 개발이나 ERP 연동 개발도 견적을 받을 수 있나요?

HOW는 ERP에만 한정되지 않으며 SI 개발, 신규 웹·시스템 구축, 기존 시스템 개선, ERP 연동, API 개발 등 다양한 IT 개발 과제의 사전 견적 검토에 활용할 수 있습니다.

Q

견적 결과가 최종 개발 계약 금액인가요?

아닙니다. 입력된 요구사항을 기반으로 한 사전 검토 견적이며, 세부 기능이나 데이터 이전, 외부 시스템 연계 등의 조건에 따라 실제 비용과 일정은 달라질 수 있습니다.

Q

견적을 받으면 반드시 개발 계약을 해야 하나요?

아닙니다. HOW 견적 이용만으로 개발 계약이 의무적으로 체결되는 것은 아니며, 실제 개발을 진행하는 경우 별도의 협의를 거칩니다.
